# File Monitor

Консольная утилита для мониторинга изменений файлов.

## Сборка

```bash
cmake -B build
cmake --build build
```

## Использование

```
add <path>    — добавить файл для наблюдения
remove <path> — удалить файл из наблюдения
start         — запустить мониторинг
stop          — остановить мониторинг
list          — список наблюдаемых файлов
quit          — выход
```
